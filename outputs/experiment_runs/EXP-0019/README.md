# EXP-0019 classification

This is the 80-history fallback development experiment. It is retained as a
coverage sensitivity and is not the decisive Price result.

The first run is preserved under `invalid_run_attribution_scope/` because its
top-five stock-contribution diagnostic accumulated data beyond 2020. Selection
metrics were correctly sliced and the operational choice did not change after
the hard cutoff was added. The corrected top-level run uses the hard 2020 data
boundary.

EXP-0021 supersedes this experiment for conclusions because a later immutable
yfinance pull completed maximum histories for all 1,069 names.
